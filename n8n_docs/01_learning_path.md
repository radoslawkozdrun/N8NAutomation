# n8n Learning Path

## Overview
This is the comprehensive Learning Path page from the n8n documentation, structured as a guide for users getting started with n8n.

## Key Sections

### 1. Join the Community
Connect with the n8n community for support and collaboration.

### 2. Set up your n8n

### 3. Try it out

### 4. Structured Courses
- **Video courses** - Visual learning materials
- **Text courses** - Written tutorials and guides

### 5. Self-hosting n8n
Guide for setting up and managing your own n8n installation.

### 6. Build a node
Advanced topic covering custom node development.

### 7. Stay updated
Information on keeping your n8n installation current.
