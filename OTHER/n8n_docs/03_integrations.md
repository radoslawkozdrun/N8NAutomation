# n8n Integrations

Based on the content from the n8n documentation (https://docs.n8n.io/integrations/)

## Overview
The Integrations section provides comprehensive coverage of n8n's extensive integration capabilities, including built-in nodes, triggers, and custom integration options.

## Built-in Nodes Categories

### 1. Core Nodes
Essential nodes for basic workflow functionality:
- **Code** - Execute JavaScript or Python code
- **HTTP Request** - Make API calls to external services
- **Webhook** - Receive HTTP requests from external systems
- **Set** - Manipulate data within workflows
- **IF** - Conditional logic branching
- **Switch** - Multi-condition routing
- **Merge** - Combine data from multiple sources

### 2. Action Nodes (100+ integrations)
Service-specific integrations including:
- **Communication**: Slack, Discord, Telegram, Email
- **Cloud Storage**: Google Drive, Dropbox, AWS S3
- **CRM**: Salesforce, HubSpot, Pipedrive
- **Project Management**: Asana, Trello, Monday.com
- **E-commerce**: Shopify, WooCommerce, Stripe
- **Social Media**: Twitter, Facebook, LinkedIn
- **Development**: GitHub, GitLab, Jira

### 3. Trigger Nodes
Event-based integrations that start workflows:
- **Webhook Trigger** - HTTP requests
- **Cron Trigger** - Time-based scheduling
- **File System Trigger** - File changes
- **Email Trigger** - Incoming emails
- **Service-specific Triggers** - Platform events

### 4. Cluster Nodes
Advanced and AI-powered nodes:
- **AI Integrations**: OpenAI, Anthropic, Google Gemini
- **LLM Nodes**: Large Language Model integrations
- **Advanced Analytics**: Data processing and ML
- **Enterprise Integrations**: Specialized business tools
