# n8n Main Overview

Based on the content from the n8n documentation (https://docs.n8n.io/)

## Welcome to n8n

n8n is a [fair-code](https://faircode.io) licensed workflow automation tool that combines AI capabilities with business process automation. It covers everything from setup to usage and development.

## What is n8n?

n8n (pronounced "n-eight-n") is an extendable workflow automation tool which enables you to connect anything to everything. It's a powerful platform that helps you:

- **Connect Apps**: Link any app with an API to any other app
- **Transform Data**: Manipulate and process data with little or no code
- **Automate Workflows**: Create complex automation scenarios
- **Build AI Functionality**: Integrate AI capabilities into your workflows
